# DeepBinary

DeepBinary is a research project on AI-assisted vulnerability discovery in Windows kernel binaries.

## Submission rules

We are not accepting public submissions at this time. Please do not upload binaries, symbols, VM images, PoCs, or unpublished vulnerability details through issues or pull requests.

## Contact

For project inquiries or sensitive reports, contact the corresponding author using the address in the accompanying paper.

## License Issues

We are coordinating with the relevant vendors on licensing and redistribution terms for the benchmark materials. We will update this repository when those discussions are resolved.
